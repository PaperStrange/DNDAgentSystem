| B-9 | 画布高度超过视口（1184px），多角色同屏布局溢出 | P0 | ✅ |

B-8/B-9 根因与修复：
- 根因1：CSS `min-height:480px` 导致挂载时测得错误高度，画布缓冲(480px)与CSS实际高度(1043px)不一致 → 垂直拉伸。修复：去除min-height、严格flex高度链（#app/#screen-root/.screen-game 全链 height:100%+min-height:0）、ResizeObserver持续同步+RAF二次校准。
- 根因2：高度链断裂（#app缺height:100%）→ 画布被侧栏内容撑到1184px。修复后画布严格贴合视口（854/1034/722）。
- 增强：缩放公式改为目标可见22列×13行(3~6倍)；多人同格堆叠错开绘制(6向偏移表)；名字/血条/悬浮伤害改屏幕空间固定像素（不随SCALE变形，多角色同屏不重叠遮挡）。
- 验证：tools/canvas-probe.mjs 三视口实测 stretchX/Y=1.000、内容长宽比1.47/2.15/2.26。
