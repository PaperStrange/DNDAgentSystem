# 报错提示审计与规范（R-22）
> 整理所有交互元素不同情况的报错提示，统一用户友好标准。最后更新：遗漏批次迭代14。

## 用户友好规范（所有提示遵循）
1. **说清发生了什么 + 该怎么办**：每条提示都要给出下一步动作，不允许只报状态。
2. **不泄露内部信息**：不出栈/字段名/文件路径/配置；密码类错误只提示"不正确"，不提示账号是否存在。
3. **语气友好**：错误用 ⚠️/❌ 前缀+安抚性措辞，禁止"未知消息""参数无效"等术语黑话。
4. **不刷屏**：相同提示 1.5 秒内去重（app.mjs toast 已实现）；自动战斗模式操作失败不弹窗（避免节拍器刷屏）。
5. **权限类提示说明归属**："只有房主可以…"；无法恢复时给出"刷新页面/重新登录"等可操作建议。

## 服务端错误提示清单（s:error → toast 弹窗）

### 账户系统（server/accounts.mjs + index.mjs）
| 场景 | 提示 |
|---|---|
| 用户名格式错误 | 用户名需2~20位，可用字母/数字/中文/下划线/连字符 |
| 密码过短/过长 | 密码长度需4~64位 |
| 用户名已存在 | 该用户名已被注册，请直接登录或换一个名字 |
| 账号不存在 | 账号不存在，请先注册 |
| 密码错误 | 密码不正确，请重试 |
| 令牌失效（被挤掉/服务器重启） | 登录状态已失效（可能在其他位置登录或服务器已重启），请重新登录 |
| 单点登录挤掉旧会话（s:auth-kicked） | 你的账号已在其他位置登录（新IP x.x.x.x）/ 已在本机其他会话登录，本连接已断开 |
| 未登录建房/加入 | 请先登录账号后再创建或加入房间（点击右上角「登录 / 注册」） |

## 客户端交互确认与提示
| 场景 | 形式 |
|---|---|
| 退出房间 | confirm「确定离开冒险并退出房间吗？」 |
| 踢人 | confirm「踢出 XX？」 |
| 被房主踢出 | toast「你被房主移出了房间」 |
| 被新登录挤掉 | toast + 1.8秒后自动刷新回登录态 |

| 保存车卡/背景生成/日志导出 | ⏳进行中 → ✅成功 / ⚠️失败 两段式 toast |
| 单人准备确认 | 弹窗二选一「⚔️立即开始冒险 / ⏳继续等待其他玩家」 |
| 非房主按快捷键调速 | toast「⚖️ …是房主专属操作」 |

## 自查机制（R-23）
1. **冒险完整日志落盘**：每次冒险结束，服务器自动把完整日志（含私密条目标注）写入房主电脑 `data/logs/{房间码}-{时间}.log`。
2. **房主手动导出**：结算页「📥 下载完整日志」按钮（仅房主可见）→ 浏览器下载 .txt。
3. **客户端错误环形缓冲**：未捕获脚本错误/未处理Promise拒绝自动记录到 localStorage（上限50条），大厅「🛠 本机报错自查」面板可展开查看/清空。
4. **服务器日志**：`DND_DEBUG=1` 启动时控制台打印 [msg]/[disp] 消息流；[logs] 标记日志落盘路径。
