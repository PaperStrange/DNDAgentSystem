“这是给莉娜的。”他说，声音像石子落入深井。蛛后倒退，节肢在石板上刮出刺耳的哀歌。但所有人都知道，它的丧钟已经敲响。

## token控制机制
1. 每场战斗常规事件（hit/miss/fumble/kill/heal）LLM加戏合计≤4次，超出自动走离线轮换语料（0 token）
2. 节流4秒，队列串行，防刷屏
3. 关键事件（开战/暴击/BOSS倒/倒地）与结局旁白不受次数上限约束，但受节流约束
4. 离线模式（无LLM配置）全量走扩充后的轮换语料，0 token
