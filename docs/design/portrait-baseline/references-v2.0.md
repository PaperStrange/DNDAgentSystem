## 二、种族特征考据（红线-8：每对象 ≥2-3 项参考）

### R1 人类（男）
- 来源1：老板提供的人类参考图（群内附件，S3-1 沿用）——要点：五官轮廓清晰分离、眼睛一眼可读
- 来源2：DnDBeyond 人类种族立绘范式（同上链接）——要点：平凡可信的面部结构，无明显奇幻符号，靠发型/肤色/服饰区分个体
- 来源3：Reddit r/DnD 角色立绘社区常见人类战士/法师肖像——要点：半写实档需保留「玩家代入感」，避免过度英雄化

### R2 精灵
- 来源1：DnDBeyond 精灵（Elf）物种页——要点：尖耳为第一特征，耳长≈半脸，银/金色长发
- 来源2：Wargamer 全种族解析（https://www.wargamer.com/dnd/races）——要点：面部纤细、颧骨高、瞳色明亮
- 来源3：S3-1 双审结论——要点：长发必须读作头发（冠顶参差起伏，禁平滑穹面），贴面下延过肩

### R3 矮人
- 来源1：DnDBeyond 矮人（Dwarf）物种页——要点：络腮胡占面部下半 ≥40%，浓眉
- 来源2：花瓣矮人概念设计集（https://m.huaban.com/pins/1449151069/）——要点：厚涂档矮人强调体积感与金属饰件
- 来源3：S3-1 双审结论——要点：秃顶+双侧发为第一特征，头顶禁带状高光（防束发带/帽子误读），改稀疏散点油光

### R4 半身人
- 来源1：DnDBeyond 半身人（Halfling）物种页——要点：卷发、红润脸颊、亲和表情
- 来源2：Wargamer 全种族解析——要点：体型小巧但候选头像档不依赖体型，靠卷发+腮红辨识
- 来源3：S3-1 基准——要点：卷发纹理清晰、绿瞳

### R5 半兽人
- 来源1：DnDBeyond 半兽人（Half-Orc）物种页——要点：绿/灰绿皮肤、下獠牙外露、红瞳常见
- 来源2：Wargamer 全种族解析——要点：眉弓突出、下颌宽大
- 来源3：S3-1 基准——要点：獠牙为第一特征（白色两点清晰），发际线参差避免头盔误读

### R6 龙裔
- 来源1：DnDBeyond 龙裔（Dragonborn）物种页——要点：鳞覆头部、前突吻部、无发、竖瞳/琥珀瞳
- 来源2：花瓣龙裔立绘（https://m.huaban.com/pins/5808124547/ 合集内）——要点：厚涂档用不规则鳞簇+圆柱光影表现吻部，禁规整网格（=织物误读）
- 来源3：S3-1 双审结论——要点：鳞片疏密错落、局部留肤色基底；吻部中央亮脊+两侧深转折

### R7 侏儒
- 来源1：DnDBeyond 侏儒（Gnome）物种页——要点：蓬乱短发/火红发色、大眼、表情生动
- 来源2：Wargamer 全种族解析——要点：五官比例偏大（眼占比高）是可爱感来源
- 来源3：S3-1 双审结论——要点：蓬发外轮廓参差，禁闭合眼框（防眼镜误读）

### R8 半精灵
- 来源1：DnDBeyond 半精灵（Half-Elf）物种页——要点：耳微尖（短于精灵）、发色多样
- 来源2：贴吧半精灵吟游诗人自画像（https://tieba.baidu.com/p/2586436617）——要点：人类基底+轻度精灵化的过渡感
- 来源3：S3-1 基准——要点：尖耳可辨但不过度，发长读感自然
