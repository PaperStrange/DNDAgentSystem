## 三、4 级肤色过渡体系

### 3.1 色阶定义

| 级别 | 名称 | 变量 | 用途 | 相对基色 |
|---|---|---|---|---|
| L0 | 高光 | `T` | 受光面（额头/鼻梁/下颏/左脸） | +20% 明度 |
| L1 | 基色 | `s` | 面部主体填充 | 基准 |
| L2 | 阴影 | `S` | 背光面（右脸/下颏侧/刘海投影/颈前） | -15% 明度 |
| L3 | 深影 | `M`/暗角 | 最深凹陷（唇下/耳内/鼻底/颈侧） | -25% 明度 |

### 3.2 过渡规则

1. **光源方向**：左上（方位角 135deg，仰角 45deg）
2. **高光区（L0）**：额头左侧(x=12-14, y=9)、鼻梁(x=15, y=15-17)、下颏中央(x=15-16, y=24)、左脸颊(x=10-12, y=11-13)
3. **基色区（L1）**：面部中心大面积
4. **阴影区（L2）**：右脸纵带(x=21, y=11-23)、下颏两侧(x=19-20, y=25)、刘海投影(y=9, x=10-21)
5. **深影区（L3）**：唇部暗角(x=13/18, y=22)、耳廓内影(x=7/24, y=15)、鼻底(x=15-16, y=20)

## 四、1px 全轮廓描边规则

### 4.1 描边生成算法

```
对于网格中每个像素 (x, y)：
  如果 (x, y) 为背景（未填充）且四邻域中至少一个像素为已填充：
    将 (x, y) 设为描边像素 'o'
```

四邻域定义：`(x-1,y)`, `(x+1,y)`, `(x,y-1)`, `(x,y+1)`

### 4.2 描边色值

| 场景 | 色值 | 说明 |
|---|---|---|
| 通用描边 | `#2a1a1a` | 深暖黑，与背景 `#1c1824` 明度差 > 8% |
| 龙裔描边 | `#1a2a1a` | 深绿黑，匹配龙裔色调 |

### 4.3 描边约束

1. **统一 1px**：所有轮廓线宽度严格 1 像素，不可 2px 或更粗
2. **闭合优先**：轮廓应形成闭合路径，不留缺口
3. **不侵入内部**：描边仅占据原本为空的背景像素，不覆盖已填充像素
4. **内部边界也描边**：如耳廓与面部之间的间隙也需描边

## 五、左上光源定义

### 5.1 光源参数

| 参数 | 值 |
|---|---|
| 方向 | 左上（方位角 135deg，从正面看光线来自左上方） |
| 仰角 | 45deg |
| 强度 | 标准（高光 +20% 明度，阴影 -15% 明度） |
| 类型 | 平行光（无衰减，全画面均匀方向） |

### 5.2 光影映射规则

| 朝向 | 光影级别 | 示例 |
|---|---|---|
| 左上朝面 | L0 高光 | 额头左半、鼻梁左侧 |
| 正面 | L1 基色 | 面部中心 |
| 右侧 | L2 阴影 | 右脸纵带 |
| 底侧 | L2-L3 阴影 | 下颏下方、鼻底、唇下 |
| 凹陷 | L3 深影 | 耳廓内部、眼眶下缘 |

### 5.3 头发光影

- 高光区：左上 2-3px（`H` 色），模拟光泽
- 基色区：头发主体
- 阴影区：右下及发梢

## 七、渲染管线规范

### 7.1 生成流程

```
1. 初始化 32x40 空网格（全部 '.'）
2. 按层次绘制：头发 -> 脸/颈 -> 耳廓 -> 躯干 -> 光影 -> 五官 -> 特殊特征
3. 执行自动描边算法（Section 四）
4. 在描边后绘制五官细节（确保五官在描边层之上）
5. 输出 SVG：每个非空像素 -> <rect x="x*12" y="y*12" width="12" height="12" fill="COLOR"/>
6. 输出 PNG：通过 Playwright 截图 SVG 或使用纯 JS PNG 编码器
```

### 7.2 完整性校验

- 脚本执行完毕后验证：
  - SVG 文件存在且非空
  - PNG 文件存在且非空
  - 像素总数 > 200（确保不是空图）
  - 无未映射字符残留
- 校验失败时删除中间文件，不留残件

### 7.3 文件命名

| 类型 | 命名格式 |
|---|---|
| SVG | `portrait-{race}-v1.0.svg` |
| PNG | `portrait-{race}-v1.0.png` |
| 脚本 | `gen-race-{race}.mjs` |

race 取值：`human-male`, `elf`, `dwarf`, `halfling`, `half-orc`, `dragonborn`, `gnome`, `half-elf`

## 八、验收标准

1. 所有 8 种族基准像在 12x 缩放下五官清晰可辨
2. 种族间视觉差异明显：即使去除色彩仅看轮廓也可辨识 >= 5 个种族
3. 描边连续闭合，无缺口或多余像素
4. 光影方向一致（左上光源），所有种族统一
5. 生成脚本可重复执行，输出一致性 100%
6. PNG + SVG 成对产出，无中间残件
