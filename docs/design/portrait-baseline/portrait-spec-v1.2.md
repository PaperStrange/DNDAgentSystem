## 〇、修订背景（用户反馈 2026-08-30）

用户反馈「人类图没眼睛」「器官轮廓模糊，远不及参考图清晰」。逐像素核验确认：

| 问题 | 根因 | v1.2 对策 |
|---|---|---|
| 眼睛数据存在但视觉不可读 | 眼部仅 2 行高，虹膜贴肤色无轮廓分隔 | 眼睛最小可读规格（§二）：4×3 + 深色眼睑线 |
| 器官之间轮廓模糊 | 器官仅靠同色系单级明度差分隔，无轮廓线 | 器官轮廓分离规则（§一）：≥2 级明度差或 1px 深轮廓 |
| 审核只看 12x 放大图 | 未在游戏实际显示尺寸验证可读性 | 1x 可读性门禁（§六） |
| 审核只验「像素存在」 | 无必读要素清单 | 必读要素清单（§五） |

面部基底（16px 脸颊 / 5 级肤色 / 鼻四段 / 双色唇 / 服装绘制规则）沿用 v1.1，本版不改动。

## 一、器官轮廓分离规则（全资产通用）

1. 相邻器官/物件之间必须满足以下之一，禁止仅靠同色系单级明度差区分：
   - ≥2 级明度差（如 L1 基色 与 L3 深影相邻）；
   - 1px 深色轮廓线（描边 token `o` 或同级深影）。
2. 人类基准像落实点：
   - 眉（`d`，y9）与眼之间：上睑深框线（`o`，y10）；
   - 眼与鼻梁之间：外眼角深框（`o`）+ 下睑阴影带（`S`）；
   - 鼻与颊之间：鼻根两侧锚点（`S`）+ 鼻翼外角深影（`D`）；
   - 唇与下颏之间：唇颏沟深影（`D`，y23）+ 下颏高光（`T`，y25）。
3. 种族差异器官（尖耳/獠牙/鳞顶/吻部）同样适用本规则，落地方式见 race-features。

## 二、眼睛最小可读规格（角色类资产通用）

1. 单眼不小于 4×3 像素（宽×高）；人类基准像坐标：左眼 x10-13 / 右眼 x18-21，眼位行 ey（常规 y11，低位眼 y12）。
2. 结构必备四件套：上睑深框线（`o`，ey-1）/ 眼白行（`e`，含高光 `k`）/ 虹膜+瞳孔分离行（`i`+`p`）/ 下睑阴影带（`S`，ey+2）。
3. 外眼角保留深框（`o`）；内眼角留眼白不做闭合框——闭合矩形框会被误读为眼镜（v1.2 自审实测）。
4. 瞳色与周围肤色明度差 ≥2 级；半兽人红瞳将内眼角眼白替换为虹膜色，保证红瞳面完整。
5. 判定标准：32×40 实际显示尺寸（1x）下，双眼必须一眼读出是「眼睛」，不得依赖放大图。

## 三、本次修订像素账（人类男性基准）

| 部位 | v1.1 | v1.2 |
|---|---|---|
| 眼 | 3×2 每只，虹膜贴肤色 | 4×3 每只，深框+眼白+虹膜/瞳孔分离 |
| 眉弓阴影行（y10） | `S` 3px | 取消，由上睑深框线承担眉眼分离 |
| 鼻根 | 单像素 `n` | +两侧锚点 `S` |
| 鼻翼外角 | `S` | `D` 深影 |
| 唇颏沟 | `S` | `D` 深影 |
| 总像素 | 748 | 748（器官改造为原位替换，总量不变） |

种族侧同步改动：7 种族统一新眼结构；矮人秃顶高光改散点油光（消除帽子误读）；龙裔亮鳞 token 降为中亮 `#86a890`（消除头骨误读）+ 不规则错落鳞簇 + 吻部圆柱光影（Kevin 裁定返工项）；龙裔颊鳞下移避开眼睑框。

## 四、生成与校验管线

- 生成脚本：`gen-baseline-v11.pl`（人类基准，产出 portrait-human-male-v1.2.svg）、`gen-all-races-v11.pl`（7 种族，产出 portrait-{race}-v1.1.svg）。
- 转换工具：`svg2png.pl`（纯 Perl，支持任意尺寸：384×480 审核图 / 32×40 1x 自检图）。
- 脚本内置门禁：对称性校验（不对称 >2 即失败）、像素量下限。

## 五、必读要素清单（提审强制项，红线-6 第 7 条）

| 资产类型 | 必读要素（1x 尺寸逐要素核验） |
|---|---|
| 角色肖像 | ① 双眼一眼可读 ② 眉/鼻/唇可定位 ③ 种族第一特征可指认（精灵尖耳+长发 / 矮人络腮胡+秃顶 / 半身人卷发+腮红 / 半兽人红瞳+獠牙 / 龙裔鳞顶+吻部 / 侏儒蓬发+大眼 / 半精灵微尖耳+中长发）④ 轮廓剪影完整 |
| 地图 | 可通行区 / 不可通行区 / 关键地标 / 玩家位置 |
| BOSS 外观 | 轮廓剪影 / 辨识部位 / 弱点暗示 |

提审材料必须附「必读要素清单 + 逐要素命中记录」，缺项视为提审无效。

## 六、1x 可读性门禁与三档审查（红线-6 第 8 条）

1. 提审必须附两档图：12x 放大图（384×480，供细节审查）+ 1x 实际尺寸图（32×40，供可读性审查）。
2. 三档审查：1x 可读性 → 放大细节 → 去色对比度；另执行盲读（审核人不被告知设计意图直接描述所见），要素未命中即打回。
3. 禁止以「像素存在、对称性为 0」作为通过依据。

## 七、参考先行工作方法（流程改进，红线-6 第 9 条关联）

1. 任何新资产动笔前，必须先收集同品类参考（用户提供 + 网络检索同类像素画/游戏素材），并在规范文档中登记参考来源与提炼结论。
2. 本次事故反思：8 种族仅凭 1 张人类参考图推演其余种族视觉，未做外部参考检索，是本版返工的直接根因之一。后续各种族定稿前补齐对应种族像素肖像参考检索记录。
