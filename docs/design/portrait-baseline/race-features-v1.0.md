# 8 种族专属视觉特征定义

> 作者：Hua（设计 Owner）| 版本：1.0 | 日期：2026-08-29
> 配套文档：portrait-spec-v1.0.md（绘制规范）、gen-all-races.mjs（生成管线）
> 画布：32x40 像素，12x 缩放

---

## 总览

8 种族在 32x40 肖像中的差异化策略：

| 维度 | 差异化手段 | 辨识度贡献 |
|---|---|---|
| 肤色 | 每种族独立 4 级色阶 | 高 — 第一印象 |
| 发色/发型 | 种族特色发色 + 发型轮廓 | 高 — 头顶轮廓 |
| 耳型 | 尖耳/正常耳/隐藏耳 | 极高 — 侧面轮廓 |
| 面部比例 | 下颌宽窄/额高/眼大小 | 中 — 细看可辨 |
| 专属特征 | 胡须/獠牙/鳞片/腮红等 | 极高 — 种族标志 |

---

## 1. 人类 (Human)

**基准像**：人类男性 v0.1（已验证）

### 五官比例
- 面部标准比例，对称轴 x=15.5
- 眉宽 4px，眼宽 3px，眉间距 = 眼间距 = 4px
- 下颌中等宽度（y=25: x=10-21）

### 肤色基色
| 级别 | 色值 | 说明 |
|---|---|---|
| L0 高光 | `#f7d3a8` | 暖调明亮 |
| L1 基色 | `#e8b183` | 标准暖肤色 |
| L2 阴影 | `#c17d55` | 暖调阴影 |
| L3 深影 | `#a06040` | 深暖影 |

### 专属特征
- 无超自然特征
- 发型多样（基准像为中等短发）
- 可蓄短须/长须（由捏脸系统控制）

### 头发
- 基色：`#5b3a24`（深棕）
- 高光：`#8a5a33`（左上 2-3px）
- 覆盖区域：y=2-8，宽度 x=8-23

---

## 2. 精灵 (Elf)

### 五官比例
- 面部略窄于人类（下颌 y=25: x=10-21, y=26: x=11-20, y=27: x=12-19）
- 下颌更尖（收窄更快）
- 眼睛略大（视觉重心偏上）
- 眉毛更纤细优雅

### 肤色基色
| 级别 | 色值 | 说明 |
|---|---|---|
| L0 高光 | `#fce8d8` | 极浅，近乎月光白 |
| L1 基色 | `#f0c8a0` | 浅象牙色 |
| L2 阴影 | `#d0a078` | 柔和暖影 |
| L3 深影 | `#b08060` | 浅深影 |

### 专属特征
- **尖耳**：从耳廓位置(x=6-7/24-25, y=13-16)向外上方延伸
  - 左耳尖：延伸至 x=4, y=12 和 x=3, y=11
  - 右耳尖：延伸至 x=27, y=12 和 x=28, y=11
  - 耳长比人类多 3-4px
- 面部无胡须（精灵男性通常无须）
- 长发贴面（鬓角延伸至 y=16）

### 头发
- 基色：`#c8c0d0`（银灰紫）
- 高光：`#e8e0f0`（银白光泽）
- 长发：两侧延伸至 y=16，覆盖鬓角区域

---

## 3. 矮人 (Dwarf)

### 五官比例
- 面部宽于人类（整体宽 1-2px）
- 下颌极宽（y=25: x=9-22）
- 眉骨突出（双层眉毛）
- 鼻子宽大（4x2px vs 人类 2x3px）
- 眼睛略小（被浓眉和颧骨压缩）

### 肤色基色
| 级别 | 色值 | 说明 |
|---|---|---|
| L0 高光 | `#f0c8a0` | 偏暖 |
| L1 基色 | `#d8a070` | 偏红褐（日晒铜皮） |
| L2 阴影 | `#b07848` | 深暖褐 |
| L3 深影 | `#906030` | 深褐 |

### 专属特征
- **浓密络腮胡**：覆盖 y=19 至 y=31（从嘴下到胸口）
  - 宽度：x=8-22（几乎与脸同宽）
  - 逐渐收窄至 x=13-18（y=31）
  - 胡须基色：`#8a4a22`（红棕）
  - 胡须高光：`#b06a32`
- **秃顶侧发**：头顶无发（y=3-5 为皮肤），仅两侧有发(y=5-14)
- 双层浓眉（y=11 和 y=12 两行）

### 头发
- 基色：`#8a4a22`（红棕）
- 仅两侧鬓角，无头顶覆盖

---

## 4. 半身人 (Halfling)

### 五官比例
- 面部圆而宽（下颌圆润，y=25-27 收窄缓慢）
- 眼睛比例略大（可爱感）
- 鼻子小巧
- 嘴部略宽（微笑感）

### 肤色基色
| 级别 | 色值 | 说明 |
|---|---|---|
| L0 高光 | `#f8d8b0` | 明亮暖色 |
| L1 基色 | `#e8b888` | 健康暖肤色 |
| L2 阴影 | `#c89060` | 暖褐 |
| L3 深影 | `#a87040` | 深暖 |

### 专属特征
- **圆润脸颊**：面部宽度比人类多 1px（y=15-22 区域）
- **卷发**：头顶蓬松，发量视觉多（y=2-8 向外扩 1px）
- **腮红**：颧骨处 2px 粉色（x=9-10/21-22, y=17-18）
- 无胡须（基准像）

### 头发
- 基色：`#6a4020`（暖棕）
- 高光：`#9a6838`
- 蓬松卷曲：y=2-4 宽度 x=7-24（比人类多 1px 外扩）

---

## 5. 半兽人 (Half-Orc)

### 五官比例
- 眉骨突出（y=10 加粗 1px 眉脊）
- 下颌宽且方（y=25: x=9-22, y=26: x=10-21, y=27: x=11-20）
- 面部整体比人类宽 1px
- 眼睛略小（被眉骨压缩）

### 肤色基色
| 级别 | 色值 | 说明 |
|---|---|---|
| L0 高光 | `#88b870` | 浅绿明亮 |
| L1 基色 | `#6a9850` | 标准绿皮 |
| L2 阴影 | `#4a7830` | 深绿 |
| L3 深影 | `#306018` | 暗绿 |

### 专属特征
- **獠牙**：从下唇两侧向下突出
  - 左獠牙：x=13, y=23-25（2px 长）
  - 右獠牙：x=18, y=23-25
  - 色值：`#e8e0d0`（骨白）
- **粗重眉脊**：y=10 行加一条深色带 `#3a5828`
- 短而粗的头发（y=3-7，比人类短）
- 耳朵略尖（介于人类和精灵之间）

### 头发
- 基色：`#1a1a18`（近黑）
- 高光：`#3a3a30`
- 短发：y=3-7，宽度 x=9-22

---

## 6. 龙裔 (Dragonborn)

### 五官比例
- 面部与人类相似但更棱角分明
- 下颌更方（y=25-27 宽度一致，不收尖）
- 鼻部为吻部结构（从鼻梁延伸为突起）
- 眉脊略突

### 肤色基色
| 级别 | 色值 | 说明 |
|---|---|---|
| L0 高光 | `#98b8a0` | 浅灰绿带蓝 |
| L1 基色 | `#708878` | 灰绿（鳞片感） |
| L2 阴影 | `#506858` | 深灰绿 |
| L3 深影 | `#384840` | 暗灰绿 |

### 专属特征
- **鳞片纹理**：面部散布鳞片色 `c`=`#587868` 和 `C`=`#88a898`
  - 右颊：x=19-21, y=15-18 区域 3-4 个鳞片点
  - 额头：x=12-14, y=9-10 区域 2 个鳞片点
  - 颈部：x=14-17, y=28-29 区域 2 个鳞片点
- **吻部**：鼻梁(y=15-17)延伸为更宽的结构(x=14-17, y=18-20)
- **眉脊**：y=10 行加一条深色脊 `#405848`
- 无头发（龙裔通常无发），头顶为鳞片覆盖的皮肤
- 耳廓小且后贴

### 头发
- 无传统头发
- 头顶(y=2-7)为鳞片皮肤色，带鳞片纹理点

---

## 7. 侏儒 (Gnome)

### 五官比例
- 面部圆而短（y=8-25，比人类少 2 行）
- 眼睛比例大（3x2 -> 4x2，每侧多 1px）
- 鼻子小而翘
- 下巴圆

### 肤色基色
| 级别 | 色值 | 说明 |
|---|---|---|
| L0 高光 | `#f8d0b0` | 明亮暖色 |
| L1 基色 | `#e8b090` | 偏粉暖肤 |
| L2 阴影 | `#c88868` | 暖褐 |
| L3 深影 | `#a86848` | 深暖 |

### 专属特征
- **大眼**：每侧眼睛 4px 宽（x=10-13 / x=18-21 vs 人类 3px）
- **腮红**：颧骨处明显粉色（x=9-10/21-22, y=16-17）
- **蓬松野发**：发量极大，向两侧蓬出
  - y=2-4: x=6-25（比人类多 2px 外扩）
  - y=5-8: x=7-24
- 无胡须（基准像）

### 头发
- 基色：`#a83820`（红棕/姜色）
- 高光：`#d05830`
- 极蓬松：覆盖面积比人类大 ~30%

---

## 8. 半精灵 (Half-Elf)

### 五官比例
- 介于人类和精灵之间
- 面部略窄于人类（下颌 y=25: x=10-21, y=26: x=11-20）
- 下颌比精灵圆、比人类尖
- 眼睛略大于人类

### 肤色基色
| 级别 | 色值 | 说明 |
|---|---|---|
| L0 高光 | `#fce0c8` | 浅暖 |
| L1 基色 | `#f0c098` | 暖象牙 |
| L2 阴影 | `#d09870` | 暖褐 |
| L3 深影 | `#b07850` | 深暖 |

### 专属特征
- **微尖耳**：介于人类和精灵之间
  - 耳廓基础同人类(x=6-7/24-25, y=14-16)
  - 尖端延伸较短：仅到 x=5, y=13 / x=26, y=13（比精灵短 2px）
- 发色带银调（棕发 + 银色光泽）
- 面部光滑（无胡须，基准像）

### 头发
- 基色：`#7a5a40`（棕带银）
- 高光：`#b8a080`（银棕光泽）
- 中长：两侧延伸至 y=14
